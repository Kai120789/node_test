# Download speed test

Консольный скрипт на Node.js. Принимает URL, делает к нему **10 запросов подряд**, дожидается полного тела каждого ответа и печатает:

- среднее время одного запроса;
- суммарный объём скачанных данных;
- скорость скачивания.

Зависимостей нет: используется встроенный `fetch` (Node.js 18+).

## Единицы

| Что измеряем | Единица | Как считается |
| --- | --- | --- |
| Время запроса | миллисекунды (**ms**) | от старта `fetch` до полного чтения тела ответа |
| Объём | мебибайты (**MiB**) | 1 MiB = 1 048 576 байт. Рядом печатается точный размер в байтах |
| Скорость | мегабиты в секунду (**Mbit/s**) | `(всего байт × 8) / суммарное время всех запросов в секундах / 1 000 000` |

1 Mbit/s = 1 000 000 бит/с — так скорость обычно указывают провайдеры.

В скорость входит всё время запроса: установка соединения, ожидание первого байта и сама передача. На маленьком файле цифра будет низкой из‑за задержки, а не из‑за канала. Для замера берите тяжёлый ресурс, хотя бы несколько мегабайт.

## Запуск

Нужен Node.js 18 или новее.

```bash
node speedtest.js <url>
```

Пример с файлом на 5 МБ (эндпоинт Cloudflare, отдаёт ровно запрошенное число байт):

```bash
node speedtest.js "https://speed.cloudflare.com/__down?bytes=5000000"
```

Тот же запуск через npm:

```bash
npm start -- "https://speed.cloudflare.com/__down?bytes=5000000"
```

Кавычки вокруг URL нужны, если в адресе есть `?` или `&` — иначе оболочка воспримет их как свои символы.

## Пример вывода

```
URL:      https://speed.cloudflare.com/__down?bytes=5000000
Requests: 10, one after another

   1  HTTP 200          4.77 MiB     812 ms
   2  HTTP 200          4.77 MiB     640 ms
   ...
  10  HTTP 200          4.77 MiB     701 ms

Average request time: 690 ms
Total downloaded:     47.68 MiB (50000000 bytes)
Download speed:       579.71 Mbit/s
```

Цифры зависят от канала и от того, куда стучится скрипт.

## Ошибки

- Нет аргумента или это не `http`/`https` URL — скрипт печатает подсказку и завершается с кодом 1.
- Сеть недоступна, таймаут или ответ не 2xx — текущий запрос прерывает прогон, среднее и скорость не печатаются. Частичный результат по оставшимся запросам не считается.
